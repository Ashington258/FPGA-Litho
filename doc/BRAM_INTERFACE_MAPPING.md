# BRAM接口地址映射文档

> 创建日期: 2026-04-03  
> 目标: 定义AXI-Lite控制接口和BRAM存储区域的地址映射规范

---

## 一、地址空间布局

### 1.1 总体地址空间

| 区域 | 起始地址 | 结束地址 | 容量 | 用途 |
|------|----------|----------|------|------|
| **控制寄存器** | 0x00000000 | 0x0000FFFF | 64KB | AXI-Lite控制接口 |
| **BRAM存储** | 0x00010000 | 0x0008FFFF | 512KB | 数据存储区域 |

### 1.2 地址空间分配原则

- **控制寄存器**: 固定在低地址区域 (0x0000xxxx)
- **数据存储**: 每类数据分配独立64KB区域 (0x0001xxxx, 0x0002xxxx, ...)
- **对齐要求**: 所有地址按4字节对齐 (复数按8字节对齐)
- **避免重叠**: 各区域严格分离，便于调试和扩展

## 二、AXI-Lite控制寄存器映射

### 2.1 控制参数寄存器 (只写)

| 寄存器 | 地址 | 数据类型 | 位宽 | 说明 |
|--------|------|----------|------|------|
| `mode` | 0x00000000 | int | 32-bit | 工作模式选择 |
| `Lx` | 0x00000004 | int | 32-bit | 频域尺寸X方向 |
| `Ly` | 0x00000008 | int | 32-bit | 频域尺寸Y方向 |
| `Nx` | 0x0000000C | int | 32-bit | TCC/SOCS尺寸X方向 |
| `Ny` | 0x00000010 | int | 32-bit | TCC/SOCS尺寸Y方向 |
| `srcSize` | 0x00000014 | int | 32-bit | 光源尺寸参数 |
| `nkernels` | 0x00000018 | int | 32-bit | SOCS核数量 |

**参数取值范围**:
- `mode`: 1 (TCC模式) 或 2 (SOCS模式)
- `Lx, Ly`: 1 ~ 64 (频域尺寸)
- `Nx, Ny`: 1 ~ 3 (TCC模式限制) 或 1 ~ 15 (SOCS模式)
- `srcSize`: 32 ~ 64 (光源网格尺寸)
- `nkernels`: 1 ~ 8 (SOCS核数量)

### 2.2 控制信号寄存器

| 寄存器 | 地址 | 数据类型 | 位宽 | 说明 |
|--------|------|----------|------|------|
| `start` | 0x0000001C | int | 32-bit | 启动控制 (写1启动，自动清零) |

### 2.3 状态寄存器 (只读)

| 寄存器 | 地址 | 数据类型 | 位宽 | 说明 |
|--------|------|----------|------|------|
| `status` | 0x00000020 | int | 32-bit | 状态码 (见下表) |

**状态码定义**:
| 状态值 | 含义 | 说明 |
|--------|------|------|
| 0 | IDLE | 系统空闲，可接收新命令 |
| 1 | RUNNING | 计算进行中，不可中断 |
| 2 | DONE | 计算完成，可读取结果 |
| 3 | ERROR | 参数错误或越界访问 |

### 2.4 BRAM数据访问寄存器 (可选)

| 寄存器 | 地址 | 数据类型 | 位宽 | 说明 |
|--------|------|----------|------|------|
| `bram_addr` | 0x00000024 | int | 32-bit | BRAM访问地址 |
| `bram_data_real` | 0x00000028 | float | 32-bit | BRAM数据实部 |
| `bram_data_imag` | 0x0000002C | float | 32-bit | BRAM数据虚部 |

**用途**: 通过寄存器接口直接读写BRAM存储 (备选方案)

## 三、BRAM存储区域映射

### 3.1 光源数据存储 (source_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00010000 |
| **结束地址** | 0x0001FFFF (64KB区域上限) |
| **数据类型** | complex<float> |
| **存储容量** | 4096个复数元素 (64×64) |
| **实际占用** | 4096 × 8B = 32KB |
| **BRAM块数** | 32KB / 18Kb ≈ **18块** |

**地址计算公式**:
```
source[i] 地址 = 0x00010000 + i × 8
其中 i = [0, 4095], 对应 (y×64 + x)
```

**数据编码格式**:
```
地址 0x00010000: source[0].real (float)
地址 0x00010004: source[0].imag (float)
地址 0x00010008: source[1].real
地址 0x0001000C: source[1].imag
...
地址 0x0001FFFC: source[4095].imag
```

### 3.2 掩模频谱存储 (mask_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00020000 |
| **结束地址** | 0x0002FFFF |
| **数据类型** | complex<float> |
| **存储容量** | 4096个复数元素 (64×64) |
| **实际占用** | 32KB |
| **BRAM块数** | **18块** |

**地址计算公式**:
```
mask_fft[i] 地址 = 0x00020000 + i × 8
```

### 3.3 TCC矩阵存储 (tcc_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00030000 |
| **结束地址** | 0x0003FFFF |
| **数据类型** | complex<float> |
| **存储容量** | 225个复数元素 (15×15, Nx=3时) |
| **实际占用** | 225 × 8B = 1.8KB ≈ 2KB |
| **BRAM块数** | **1块** |

**地址计算公式** (Nx=3, Ny=3):
```
tcc[i,j] 地址 = 0x00030000 + (i×15 + j) × 8
其中 i,j = [0, 14], 共225个元素
```

**注意**: TCC矩阵为对称矩阵，仅存储上三角部分可节省存储

### 3.4 SOCS核存储 (kernels_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00040000 |
| **结束地址** | 0x0004FFFF |
| **数据类型** | complex<float> |
| **存储容量** | 1800个复数元素 (8核×225) |
| **实际占用** | 1800 × 8B = 14.4KB ≈ 14KB |
| **BRAM块数** | **8块** |

**地址计算公式**:
```
kernels[k][i] 地址 = 0x00040000 + (k×225 + i) × 8
其中 k = [0, 7] (核索引)
      i = [0, 224] (核内元素索引)
```

### 3.5 SOCS权重存储 (scales_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00050000 |
| **结束地址** | 0x0005001F |
| **数据类型** | float |
| **存储容量** | 8个浮点数 |
| **实际占用** | 8 × 4B = 32B |
| **BRAM块数** | <1块 (寄存器实现) |

**地址计算公式**:
```
scales[k] 地址 = 0x00050000 + k × 4
其中 k = [0, 7]
```

### 3.6 频域输出存储 (imgf_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00060000 |
| **结束地址** | 0x0006FFFF |
| **数据类型** | complex<float> |
| **存储容量** | 4096个复数元素 (64×64) |
| **实际占用** | 32KB |
| **BRAM块数** | **18块** |

**地址计算公式**:
```
imgf[i] 地址 = 0x00060000 + i × 8
```

### 3.7 空间域输出存储 (img_out_bram)

| 项目 | 参数 |
|------|------|
| **起始地址** | 0x00070000 |
| **结束地址** | 0x00070D0C |
| **数据类型** | float |

**地址计算公式**:
```
img_out[i] 地址 = 0x00070000 + i × 4

```

## 五、数据编码格式详解

### 5.1 复数数据编码

**存储格式**: [real, imag] 交替存储，每个复数占8字节

**字节序**: Little-Endian (ARM/x86标准)

**数据类型**: IEEE 754 单精度浮点数 (float32)

**示例**: 复数 `z = 1.5 + 2.3j` 的存储布局

| 地址偏移 | 字节内容 | 数据类型 | 值 |
|----------|----------|----------|-----|
| +0 | 0x3FC00000 | float32 | 1.5 (real) |
| +4 | 0x40133333 | float32 | 2.3 (imag) |

### 5.2 浮点数编码

**存储格式**: 连续存储，每个浮点数占4字节

**数据类型**: IEEE 754 单精度浮点数 (float32)

**示例**: 浮点数 `f = 3.14` 的存储布局

| 地址偏移 | 字节内容 | 数据类型 | 值 |
|----------|----------|----------|-----|
| +0 | 0x4048F5C3 | float32 | 3.14 |

### 5.3 整数编码 (控制寄存器)

**存储格式**: 32-bit整数，小端字节序

**数据类型**: int32 (有符号整数)

**示例**: 模式参数 `mode = 1` 的存储布局

| 地址偏移 | 字节内容 | 数据类型 | 值 |
|----------|----------|----------|-----|
| +0 | 0x00000001 | int32 | 1 |

## 六、访问时序要求

### 6.1 数据加载阶段

**典型流程**:
1. 检查状态寄存器 `status == 0` (IDLE)
2. 按地址顺序写入数据 (建议批量传输)
3. 验证数据完整性 (可选)
4. 配置参数寄存器
5. 启动计算

**时序约束**:
- 写入间隔: ≥1时钟周期 (AXI-Lite标准)
- 批量写入: 可连续写入，无等待要求
- 数据准备: 所有输入数据必须在启动前完成加载

### 6.2 计算阶段

**状态监控**:
- 启动后: `status == 1` (RUNNING)
- 等待时间: 根据计算复杂度 (SOCS~5ms, TCC~10ms)
- 完成标志: `status == 2` (DONE)

**禁止操作**:
- RUNNING状态不可写入新数据
- RUNNING状态不可修改参数
- RUNNING状态不可重新启动

### 6.3 结果读取阶段

**典型流程**:
1. 等待 `status == 2` (DONE)
2. 按地址顺序读取输出数据
3. 验证数据完整性
4. 重置状态或准备下一次计算

**读取时序**:
- 读取间隔: ≥1时钟周期
- 批量读取: 可连续读取，无等待要求
- 数据有效期: 结果数据在下次启动前有效

## 七、错误处理机制

### 7.1 参数错误检测

| 错误类型 | 检测条件 | status值 | 处理方法 |
|----------|----------|----------|----------|
| 模式错误 | `mode ∉ {1, 2}` | 3 | 检查mode参数 |
| 尺寸超限 | `Lx/Ly > 64` | 3 | 检查Lx/Ly参数 |
| TCC Nx超限 | `mode=1 && Nx>3` | 3 | 检查Nx参数 |
| 核数量超限 | `nkernels > 8` | 3 | 检查nkernels |

### 7.2 数据访问错误检测

| 错误类型 | 检测条件 | 处理方法 |
|----------|----------|----------|
| 索引越界 | `idx > MAX_SIZE` | 拒绝写入，记录错误 |
| 地址重叠 | 写入非法地址 | 拒绝访问 |
| 未加载数据 | 启动时数据缺失 | 返回ERROR状态 |

### 7.3 状态恢复方法

**错误恢复流程**:
1. 读取 `status == 3` (ERROR)
2. 检查错误日志或调试寄存器
3. 修正错误参数或数据
4. 写入 `status = 0` (复位到IDLE)
5. 重新启动计算

## 八、主机驱动实现指南

### 8.1 PYNQ驱动示例

```python
# 读取复数数据
def read_complex(driver, base_addr, idx):
    addr = base_addr + idx * 8
    real = driver.ip.read(addr)
    imag = driver.ip.read(addr + 4)
    return complex(real, imag)

# 写入复数数据
def write_complex(driver, base_addr, idx, val):
    addr = base_addr + idx * 8
    driver.ip.write(addr, struct.pack('f', val.real))
    driver.ip.write(addr + 4, struct.pack('f', val.imag))
```

### 8.2 批量传输优化

**建议**: 使用PYNQ的批量写入接口减少传输开销

```python
# 批量加载光源数据
def load_source_batch(driver, source_data):
    flat_data = source_data.flatten()
    buffer = np.zeros(len(flat_data) * 2, dtype=np.float32)
    buffer[0::2] = flat_data.real
    buffer[1::2] = flat_data.imag
    
    driver.ip.write(driver.ADDR_SOURCE_BASE, buffer.tobytes())
```
