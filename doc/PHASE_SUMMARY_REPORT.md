## 四、关键技术亮点

### 4.1 架构优化

| 技术           | 问题                     | 解决方案         | 效果         |
| -------------- | ------------------------ | ---------------- | ------------ |
| 累加器链式依赖 | 浮点加法无法在单周期完成 | 8通道并行累加器  | 频率提升7.2x |
| AXI访问依赖    | 循环内直接访问造成延迟   | 本地BRAM缓存     | 频率提升12x  |
| 存储访问冲突   | 多端口访问同一数组       | 数组分区(cyclic) | II从无效到1  |
| 三角函数延迟   | sin/cos计算耗时          | 查找表替代       | 延迟降低90%  |

### 4.2 HLS优化Pragma

```cpp
// 流水线优化
#pragma HLS PIPELINE II=1

// 数组分区
#pragma HLS ARRAY_PARTITION variable=array cyclic factor=4

// 数据流
#pragma HLS DATAFLOW

// 循环展开
#pragma HLS UNROLL factor=4

// 存储绑定
#pragma HLS BIND_STORAGE variable=array type=RAM_2P impl=BRAM
```

### 4.3 DSP资源映射

- 复数乘法: 4个DSP (2 fmul + 2 fadd)
- 累加器: 自动映射到DSP48
- 浮点运算: 使用full_dsp配置
